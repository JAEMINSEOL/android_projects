# 클로드 코드 — 데일리 매매 포트폴리오 리포트 생성 프롬프트

> **사용법**: 이 파일 전체를 Claude Code 터미널에 붙여넣거나,
> `claude < 클로드코드_데일리_포트폴리오_프롬프트.md` 로 실행하세요.
> 실행 전 아래 전제 조건을 반드시 확인하세요.

---

## 전제 조건 (실행 전 체크)

- [ ] `config.py` 에 APP_KEY, APP_SECRET 입력 완료
- [ ] `data/features.csv` 존재 (collect_data.py 실행 완료)
- [ ] `models/xgb_model.json` 존재 (train_model.py 실행 완료)
- [ ] 현재 디렉터리: 4개 스크립트가 있는 프로젝트 폴더

---
